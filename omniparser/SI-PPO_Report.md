# SI-PPO: 고령자 인지 패턴 모사를 위한 강화학습 정책

## 📋 개요

**SI-PPO(Senior-Informed PPO)**는 키오스크와 같은 복잡한 화면 인터페이스에서 고령자의 인지 패턴을 모사하여 탐색하는 AI 정책입니다. 단순히 최적 경로를 찾는 것이 아니라, **고령자처럼 천천히, 신중하게, 가끔은 실수를 하도록** 화면을 탐색하는 행동 패턴을 학습합니다.

## 🎯 핵심 목표

- **고령자 인지 신호 활용**: 6가지 인지 신호를 관찰에 포함하여 인간형 의사결정 단서 제공
- **시각적 가이드 제공**: 힌트 지도와 살리언시를 통한 중요 위치 유도
- **행동 패턴 설계**: 손설계 보상 시스템으로 고령자다운 탐색 습관 유도

## 🔧 기술적 특징

### 1. 고령자 인지 신호 (Appraisal 6D)
- **모티베이션**: 중앙시야/고대비 선호도
- **확실성**: 나이에 따른 감소 패턴
- **새로움**: 미방문 영역 비율
- **목표 일치**: 현재 목표와의 일치도
- **대처능력**: 경험과 손끝 오차 반영
- **기대감**: 확실성과 새로움의 조합

### 2. 약한 가이드 시스템
- **힌트 지도**: 화면에서 중요해 보이는 위치를 지도값으로 제공
- **살리언시**: 시각적 주목도를 통한 자연스러운 유도
- **거리 보상**: 멀리 점프할 때 패널티 적용

### 3. 다층 보상 시스템
```
- 첫 방문 보상: +0.35
- 텍스트 첫 방문: +0.30
- 방향 연속 보상: +0.03
- 점프 패널티: -0.03 × (거리-1)
- 행/열 완주 보상: +0.4
- 가장자리 보상: +0.1
- 중복 방문 가변 패널티: -0.08
```

## 🏗️ 시스템 구조

### 환경 설정
- **화면 분할**: 9×9 격자로 시야 분할
- **이동 방향**: 8방향 이동 (상하좌우 + 대각선)
- **학습 환경**: CUDA 가속 PPO 구현 (단, CPU 환경에서는 일반 CPU기반 paddleOCR 수행)

### 하이퍼파라미터
- **학습률**: 3e-4
- **배치 크기**: 512
- **GAE**: γ=0.99, λ=0.95
- **업데이트 횟수**: 6회/스텝
- **엔트로피**: 0.10 (탐험 유지)

## 📊 평가 지표

### 성능 지표
- **Coverage@T**: 제한 스텝 내 화면 커버 비율
- **Text-Recall@T**: 텍스트 첫 방문 비율

### 행태 유사성 지표
- **평균 이동거리**: 짧은 스텝 선호도 (↓)
- **방향 연속성**: 같은 방향 유지 비율 (↑)
- **중복 방문률**: 같은 칸 재방문 방지 (↓)
- **라인/열 완주 수**: 체계적 탐색 (↑)
- **가장자리 접촉률**: 적정 수준 유지

## 🔄 비교 분석

| 구분 | Vanilla PPO | AG-PPO | **SI-PPO** |
|------|-------------|--------|------------|
| 목적 | 성공률 | 성공률↑(힌트) | **성공률 + 고령자다움** |
| 관찰 | 기본 | 기본+힌트 | **기본+힌트+Appraisal 6D** |
| 보상 | 단순 | 힌트 가중 | **다층 보상 시스템** |
| 궤적 | 빠르고 단도직입 | 힌트 따라가며 빠름 | **짧고 연속적, 사람스러움** |

## 🎯 적용 시나리오

### 1. 무인주문/공공 키오스크
- 연세 많은 사용자에게 친화적인 UI 이동 경로 제안
- 접근성 개선을 위한 인터페이스 검증

### 2. UX 진단 도구
- 버튼 배치, 문구, 색상 변화가 시선 이동에 미치는 영향 분석
- A/B 테스트를 통한 최적화

### 3. 접근성 연구
- 반응속도, 확실성 저하를 모사한 개선안 프로토타이핑
- 다양한 사용자 그룹별 UX 최적화

## ⚠️ 한계점 및 개선 방향

### 현재 한계
- **설계자 편향**: 데모 데이터 없이 보상/휴리스틱만으로 모사
- **환경 특이성**: 9×9 격자, 특정 보상 상수에 의존
- **개인차**: "고령자다움"의 개인별 차이

### 개선 방향
- **데모 기반 보조학습**: BC/KL 정규화를 통한 보강
- **템플릿 다변화**: 다양한 그리드 크기와 가중치 검증
- **개인별 프로파일링**: 연령/개인별 세분화된 모델링

## 📚 용어 해설

- **PPO (Proximal Policy Optimization)**: 강화학습의 표준 방법으로, 기존 정책에서 크게 벗어나지 않도록 안전하게 업데이트
- **힌트 지도**: 화면에서 중요해 보이는 칸에 점수를 준 지도
- **살리언시**: 눈에 잘 띄는 정도(색 대비, 위치 등)
- **Appraisal 6D**: 사람의 주의와 의사결정에 영향을 주는 6가지 신호
- **Coverage**: 훑어본 화면 비율
- **중복 방문**: 같은 칸을 여러 번 다시 보는 것 (낭비로 간주, 패널티 적용)
