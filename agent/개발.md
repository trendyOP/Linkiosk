 시선/클릭 로그 실시간 저장 구조 설계 (frame 단위 저장)

 고정시간 window로 로그 분할 (예: 5초 기준)

 Feature 추출 모듈 개발:

fixation duration, 클릭지연시간, 궤적길이 등

 시선→그리드 ID 매핑 및 영역 탐색도 계산

📌 2단계: 사용자 상태 분류
 비지도 클러스터링(PCA + KMeans 또는 GMM) 적용

 클러스터별 대표 시선 패턴 해석 및 라벨링 (성공 / 실패 / 인지판단지연 / 시각적혼란 /그냥 뭐먹을지 고민)

 실시간 분류 적용: 새 window에 대해 feature 추출 → 클러스터 매핑

📌 3단계: 에이전트 반응 설계
📌 3-1. 대화 기반 메뉴 설명 (Llama + TTS)
 시선 고정 ≥ 5초 시점에 해당 그리드 주변 OCR 실행

 영역 잘라내기 + OCR (easyocr or pytesseract)

 OCR 텍스트를 프롬프트에 넣어 Llama로 설명 생성

 예시 프롬프트: "이 문구는 어떤 메뉴인지 1~2문장으로 설명해줘"

 Llama local 실행 및 속도 최적화 (gguf 모델 추천)

 결과를 TTS로 음성 출력

 pyttsx3, gTTS, OpenTTS 등으로 음성 출력

 사운드 큐 또는 시각적 강조와 함께 제공

📌 3-2. UI/UX 자동 변환 (강조 효과)
 setState 기반 스타일 동적 변경 로직 개발

 변환 규칙 정의:

 텍스트 크기 확대 (fontSize ↑)

 폰트 굵기 증가 (fontWeight: bold)

 테두리 강조 (borderWidth, borderColor)

 배경 대비도 강화 (backgroundColor 어둡게 or 하이라이트)

 특정 그리드/컴포넌트에만 적용되도록 위치 매핑 구조 유지

📌 4단계: 통합 및 테스트
 전체 파이프라인 통합 테스트

 사용자 3~5명 기준으로 A/B 테스트 (정상 vs 지연)

 성능/정확도/지연시간 측정 로그 수집 및 분석

 상태별 에이전트 반응이 실제로 도움 되는지 평가
